# Sales Performance Analysis Using Excel

## Project Overview

This project involved analysing a sales dataset using Microsoft Excel to evaluate business performance, identify trends and present meaningful insights through an interactive dashboard.

The project was completed as part of my Data Analytics training at TS Academy.

## Project Objectives

- Review the dataset for possible data cleaning issues.
- Calculate key performance indicators (KPIs).
- Analyse product profitability.
- Evaluate sales representative performance based on revenue.
- Examine Cost of Goods Sold (COGS) across different cities.
- Analyse monthly customer activity to identify the worst-performing month.
- Build an interactive dashboard to present the findings.

## Tools and Techniques Used

- Microsoft Excel
- Pivot Tables
- Excel Charts
- Excel Formulas
- Interactive Slicers

## Key Performance Indicators (KPIs)

The dashboard displays three KPI cards:

- Total Revenue
- Cost of Goods Sold (COGS)
- Total Profit

## Data Analysis and Visualisations

The analysis focused on four key areas:

1. **Product by Profit:** Identified the most profitable product.
2. **Sales Representative by Revenue:** Evaluated sales representatives based on revenue generated.
3. **City by COGS:** Compared the Cost of Goods Sold across different cities.
4. **Monthly Customer Activity:** Examined customer activity across months to identify the worst-performing month.

## Interactive Dashboard

The dashboard includes two interactive slicers:

- Region
- Category

These slicers allow users to filter the dashboard and explore the sales data from different perspectives.

## Key Findings

- Laptop A13 recorded the highest profit among the products.
- Peter generated the highest revenue among the sales representatives.
- Lagos recorded the highest Cost of Goods Sold among the cities.
- May recorded the lowest monthly customer activity.
